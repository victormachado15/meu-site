Gerenciar avaliações

Prepare uma prova criptografada para compartilhar pelo link direto. O processamento ocorre neste navegador; o arquivo e as senhas não são enviados pelo gerenciador.

Importante: esta página não altera arquivos do GitHub. Somente quem tem acesso ao repositório pode publicar alterações. Um HTML original publicado sem criptografia continua acessível, inclusive no histórico e em cópias.

Use uma senha forte e única, com pelo menos 12 caracteres. Não a publique no repositório.

Para publicar, substitua o arquivo da prova pelo HTML baixado e publique o repositório. Para trocar a senha, selecione o HTML protegido, informe a senha atual e repita o processo. Guarde uma cópia privada do original.

O GitHub Pages não revoga arquivos antigos ou cópias já baixadas. Quem receber a senha também poderá compartilhar a prova.
